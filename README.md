# MarketPlace (BeatNation) - API

## Descrição

O BeatNation é uma API desenvolvida para simular um marketplace de beats musicais, permitindo que produtores publiquem seus trabalhos, definam licenças de uso e disponibilizem seus conteúdos para venda.

Além do desenvolvimento backend, o projeto possui como objetivo estudar conceitos de AppSec, explorando vulnerabilidades comuns e suas respectivas correções.

---

## Tecnologias

- ASP.NET Core
- Entity Framework Core
- SQL Server
- MediatR
- FluentValidation
- CQRS

---

## Funcionalidades

- Criação e gerenciamento de beats 🚧
- Sistema de licenciamento ✅
- Autenticação e autorização ✅
- Marketplace 🚧
